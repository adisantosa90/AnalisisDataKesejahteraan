# AnalisisDataKesejahteraan
ANALISA ALGORITMA RANDOM FOREST UNTUK KLASIFIKASI STATUS KESEJAHTERAAN SOSIAL DALAM MENDUKUNG INTERVENSI  KEMISKINAN EKSTRIM

Berikut Analisis Data Kesejahteraan menggunakan Algoritma Random Forest dengan Dataset Data Susenas Tahun 2024.
Pemrograman menggunakan bahasa Phyton dengan menggunakan Google Colabs
